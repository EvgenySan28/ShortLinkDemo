# ShortLinkDemo

Сервис коротких ссылок на .NET 10. Длинный адрес сохраняется в PostgreSQL и получает код из 8 символов. По короткой ссылке сервис отвечает редиректом на оригинал.

Страница создания: <https://short.uliantsevfamily.duckdns.org/>

## Что умеет

- Страница, где можно вставить адрес, получить короткую ссылку и скопировать её.
- `POST /links` создаёт ссылку и возвращает код, исходный адрес и полный короткий URL.
- Повтор того же адреса не создаёт новую запись: возвращается уже существующий код.
- `GET /{code}` отвечает `302` на оригинальный адрес. Неизвестный код — `404`.
- Принимаются только абсолютные `http` и `https` URL длиной до 2048 символов, без логина и пароля в адресе.
- Код случайный, из цифр и латинских букв. При совпадении генерация повторяется, уникальность кода и исходного адреса держит PostgreSQL.
- Создание ограничено: один запрос с IP за 5 секунд, лишние получают `429`.
- Редирект читает адрес из Redis (кэш на 5 минут), промах идёт в PostgreSQL.
- Каждый успешный редирект увеличивает счётчик переходов.
